🚗 Car Price Prediction System

📌 Project Overview

The Car Price Prediction System is a Machine Learning-based web application that predicts the estimated selling price of a used car based on various features such as car name, manufacturing year, present price, kilometers driven, fuel type, seller type, transmission, and ownership.

The project uses Python and Machine Learning techniques to analyze car-related data and predict prices. It provides a simple and user-friendly interface built with Streamlit.

🎯 Objectives

- Predict the estimated selling price of used cars.
- Apply Machine Learning algorithms to real-world datasets.
- Understand the relationship between car features and selling prices.
- Build an interactive web application using Streamlit.
- Help users make informed decisions when buying or selling used cars.

🛠️ Technologies Used

- Programming Language: Python
- Frontend: Streamlit
- Data Processing: Pandas, NumPy
- Machine Learning: Scikit-learn
- Model: Random Forest Regressor
- Model Deployment: Joblib

📦 Installation and Setup

1. Clone the Repository

git clone https://github.com/your-username/car-price-prediction.git

2. Navigate to Project Directory

cd car-price-prediction

3. Install Dependencies

pip install -r requirements.txt

4. Run the Application

streamlit run app.py

The application will open in your default web browser.
